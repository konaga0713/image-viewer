# RixViewer

Rust と [egui](https://github.com/emilk/egui) で作られたデスクトップ画像ビューアーです。フォルダー内の画像をサムネイルで一覧し、選択した画像を独立したサブウインドウで表示できます。

## 主な機能

- フォルダーツリーと画像サムネイル一覧
- サムネイルの選択、ダブルクリックでの表示、コンテキストメニューからの表示やプロパティ確認
- 画像の回転、拡大・縮小、アニメーション画像の再生
- サブウインドウごとの自動縮小設定
- 画像の保存とファイル情報の表示
- プラグインによる画像形式の追加

## 起動

Rust と Cargo が使える環境で、このディレクトリから実行します。

```sh
cargo run --release
```

開発中は `cargo run` でも起動できます。アプリは起動時に前回のフォルダーを開きます。フォルダーを変えるときはメイン画面の「フォルダーを開く」を選びます。

## 使い方

### メイン画面

- フォルダーツリーでフォルダーを選択すると、そのフォルダーの画像一覧を表示します。
- サムネイルをクリックすると選択、ダブルクリックするとサブウインドウで開きます。
- サムネイルの右クリックメニューから画像を開く、外部アプリで開く、プロパティを表示できます。
- 上部の設定では、新しいサブウインドウで自動縮小を使うかどうかを指定できます。

### サブウインドウ

- 「画面に合わせて自動縮小」を有効にすると、画像をウインドウ内に収まるように表示します。
- 「拡大 +」は倍率を2倍ずつ上げ、最大8倍まで拡大します。「縮小 −」は1/2ずつ下げ、最小1/8倍まで縮小します。
- 倍率を変更するとウインドウも画像サイズに合わせて変更されます。画面からはみ出す大きさにもできます。ウインドウの最小サイズは100×100ポイントです。
- 画像を切り替えると倍率は1倍に戻ります。
- 画像メニューから回転、フォルダー内の先頭・末尾への移動、保存、プロパティ表示ができます。
- 回転などの編集内容は元の画像ファイルに保存されます。編集していない画像で保存を実行すると確認画面が表示されます。
- アニメーション画像はサブウインドウ内で再生します。

### キーボード操作

| キー | 操作 |
| --- | --- |
| `←` / `→` | 同じフォルダーの前・次の画像 |
| `↑` / `↓` | 画像を含む前・次のフォルダー |
| `Ctrl` + `←` / `Ctrl` + `→` | 左・右に回転 |
| `Ctrl` + `T` / `Ctrl` + `B` | フォルダー内の先頭・末尾の画像 |
| `Ctrl` + `S` | 画像を保存 | 開いているファイル名で保存

## 対応画像形式

アプリの標準デコーダーが扱う形式は、AVIF、BMP、DDS、EXR、Farbfeld、GIF、HDR、ICO、JPEG、PNG、PNM、QOI、TGA、TIFF、WebP です。JPEG と WebP には専用の読み込み処理があります。AVIF は同梱ソースのプラグインをビルドして配置すると利用できます。追加プラグインの対応形式は、そのプラグインによります。

## AVIF プラグイン

AVIF プラグインのソースは `plugins/avif_decoder` にあります。ビルドするには、そのディレクトリで次を実行します。

```sh
cargo build --release
```

生成された `avif_decoder_plugin.dll` は、アプリの実行時作業ディレクトリにある `plugins` フォルダーへ置きます。Windows ではビルド成果物は `plugins/avif_decoder/target/release/avif_decoder_plugin.dll` です。アプリは `plugins` 直下の DLL を読み込みます。

このプラグインは libavif を動的リンクするため、`avif.dll` も必要です。現在の x64 vcpkg 構成で確認した依存 DLL は次のとおりです。

```text
アプリの実行ファイルと同じフォルダー:
  avif.dll
  dav1d.dll
  libyuv.dll
  jpeg62.dll

plugins フォルダー:
  avif_decoder_plugin.dll
```

これらの依存 DLL は、プラグイン DLL の隣ではなく、`rixviewer.exe` のあるフォルダー（例: `target/release`）に配置してください。現在の Windows ローダー設定では、プラグイン DLL を置いた `plugins` フォルダーは依存 DLL の検索先に含まれません。Windows の `PATH` に依存 DLL のフォルダーを追加する方法もあります。実際の依存 DLL は libavif のビルド構成によって異なる場合があるため、配布物では使った vcpkg 構成に合う DLL を揃えてください。
## 設定とログ

- 最後に開いたフォルダー、フォルダーツリーの幅、ログ出力設定を設定ファイルに保存します。設定ファイルは OS ごとのアプリ設定ディレクトリ内にある `RixViewer/config.toml` です。
- メイン画面の設定からログ出力を有効にすると、実行ファイルの隣に `logs` フォルダーを作り、月ごとのログファイルに記録します。

## 補足

- Windows を主な対象として実装しています。Linux では外部アプリで開く操作に `xdg-open` を使います。macOS での動作は確認していません。
- 対応形式の一覧はファイル拡張子の判定に基づきます。実際に読み込めるかはファイルの内容と利用可能なデコーダーにも依存します。
- Rust の最低対応バージョンや各 OS での配布手順は、現時点でプロジェクト内に明記されていません。
